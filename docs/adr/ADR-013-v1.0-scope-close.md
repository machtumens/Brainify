# ADR-013: v1.0 Scope Close

**Status:** Accepted
**Date:** 2026-06-06
**Author:** Richard Amadeus

---

## Context

Second Brain v1 has completed all 6 sprints, 21 user stories, and 6 Phase Gates. Phase Gate 6 criteria have been verified. This ADR formally closes the v1.0 scope and records the ship decision.

## Decision

Tag and release Second Brain v1.0 as a complete, shippable prototype.

### Phase Gate 6 — Final Verification

| Criterion | Result |
|-----------|--------|
| Apple sync: .md files ingested via cron | PASS (P23 — ADR-012 documents Vercel filesystem limitation; manual trigger verified) |
| Clean code: `grep console.* ./src` = 0 | PASS (P24) |
| Error handling: all 10 routes return `{ success, data, error }` | PASS (P24) |
| Design audit: box-shadow=0, hardcoded-hex=0, white=0 | PASS (P24, verified in P25) |
| Build: zero errors, zero warnings | PASS (P25 — final `npm run build` clean) |

### Known Issues (Documented, Not Blocking)

1. **npm audit — 4 HIGH in Next.js internal postcss** (`node_modules/next/node_modules/postcss`): PostCSS XSS via unescaped `</style>` in CSS stringify output. Fix requires `npm audit fix --force` → upgrades to Next.js 16 (breaking change). Deferred to v1.1 as scheduled maintenance.

2. **Apple sync — Vercel filesystem limitation**: iCloud Drive path is not accessible from Vercel serverless functions (documented in ADR-012). The `/api/sync` cron is production-ready; actual iCloud path must be a local server or configured mount point. For v1 prototype scope, manual trigger via POST works correctly.

3. **Performance — cold start**: Today view cold start on Vercel free tier varies by instance warm state. Target <2s on warm start; cold starts may exceed this on first request after idle period. Acceptable for single-user prototype.

## Consequences

- v1.0 scope is frozen
- All future features route to §15 future roadmap in ROADMAP.md
- Evolution Protocol (principles.md §4) triggers after 2 weeks of daily use
- Next compression session: first Sunday of July 2026 (principles.md §24)
- Repository: https://github.com/machtumens/Brainify

## What v1.0 Includes

- **21 user stories** across 8 WBS work packages — all complete
- **5 views**: Today / Goals / Test Sim / Ask AI / Textbooks
- **13 API routes**: brief, tutor, test, test-results, ingest, session, error, goals, goals/insight, textbooks, retrospective, sync, health
- **AI cascade**: Gemini Flash → Groq Llama 3.3 → OpenRouter
- **Design system**: Newsreader serif, 12 CSS tokens, 1px progress bars, zero shadows
- **Auth**: Supabase email/password + RLS on all 9 tables
- **Crons**: retrospective (Sunday 08:00), sync (every 30min)

## What v1.0 Does NOT Include (v1.1+ Backlog)

See ROADMAP.md §15 for full list. Top candidates for v1.1:
- Dead time mobile mode (PWA)
- Weekly retrospective history UI with trend charts
- Cognitive load budget + peak window detection
